## 1. 게임 개요 & 세계관

- **장르**: 2D 횡스크롤 액션 로그라이트 (방 단위 진행, 매 런 빌드 조합, 사망 시 처음부터 + 영구 성장)
- **플레이 타임**: 1런 25~40분, 정식판 클리어 15~25시간, 파고들기 50시간+
- **타깃**: 고양이를 좋아하는 캐주얼~코어 액션 유저. 귀여운 외형 + 손맛 있는 전투
- **톤**: 귀엽지만 진지한 모험. 밤의 도시와 민속 판타지가 섞인 분위기

### 세계관

밤마다 달빛이 고양이들에게 힘을 주는 마을 **냥월촌**. 어느 날 개들의 군주 **목줄왕**이 '회색 사슬'로 고양이들의 영혼 방울을 묶어 빼앗아 갔다. 마을의 여섯 영웅묘마저 영혼을 잃고 방울만 남았다.

이 세계의 고양이들은 **두 발로 서서 걷고, 옷을 입고, 무기와 마법을 다룬다**. 고양이는 목숨이 아홉이라지만, 주인공 **나비**(삼색 떠돌이 고양이)는 마을에서 유일하게 **목숨을 단 하나만** 갖고 태어난 고양이다. 그래서 목줄왕의 사슬도 나비의 영혼만은 묶지 못했다. 나비는 영웅묘들이 남긴 방울을 차고 그 힘(= 직업)을 빌려 목줄왕의 성으로 향한다.

- **목숨은 하나 (영구 사망)**: 체력이 0이 되면 그 판은 끝(게임 오버). 쓰러진 나비를 달빛 고양이가 캣타워로 데려가 '다시 꾸는 꿈'처럼 처음부터 재도전한다 — 그 판에서 얻은 각인·유물은 사라지고, 털실·달조각(메타 화폐)만 남는다. 제목 「냥생은 한 번뿐」은 이 규칙 그 자체.
- **구현됨**: 쓰러지면 슬로모션 + 영혼 고양이 이탈 → GAME OVER (도달 웨이브·처치 수) → Space 로 처음부터 재도전
- **구사일생(九死一生)**: 런 중 1회 부활하는 전설 유물 — '한 번뿐인 냥생'에 주어지는 단 한 번의 기적. 세계관의 상징 아이템.

## 2. 빌드 타깃 & 체험판 범위

| 항목 | 웹 체험판 | 정식판 (exe) |
|---|---|---|
| 빌드 | `npm run build:web` → `dist-web/` (정적 호스팅) | `npm run dist:win` → `release/*.exe` |
| 직업 | 검객, 마법사 (2종) | 6종 |
| 챕터 | 1장 뒷골목 + 보스 쥐왕 | 5장 + 히든 챕터 |
| 메타 진행 | 캣타워 1~2층 | 전층 |
| 세이브 | localStorage | `%APPDATA%/냥생은 한 번뿐/saves/*.json` (원자적 쓰기) |
| 난이도 '달의 위상' | 없음 | 0~10단계 |
| 기타 | 1장 클리어 후 정식판 안내 화면 | 업적, 도감, 데일리 시드 런 |

- 체험판 세이브는 정식판으로 가져오기를 지원한다 (내보내기 코드 → 붙여넣기).
- 체험판 분기는 `src/config/build.ts`의 `IS_DEMO`로만 판단하고, 콘텐츠 데이터에 `demo: true` 플래그를 두어 필터링한다.

## 3. 코어 루프 & 런 구조

```
캣타워(허브) ─ 직업 선택 ─▶ 1장 ─▶ 2장 ─▶ 3장 ─▶ 4장 ─▶ 5장(최종)
     ▲                     │ 방 8~12개 (분기 선택) → 보스
     │                     ▼
     └── 사망/클리어: 털실·달조각 정산 → 영구 강화 → 스토리 조각 ──┘
```

- **방 진행**: 방을 클리어하면 출구 문 2~3개가 열리고, 문 위 아이콘으로 다음 방의 종류/보상을 미리 보여준다 → 루트 선택이 곧 전략.
- **보상 리듬**: 전투방 클리어 → 각인 3택1 / 코인 / 털실 중 하나. 엘리트 → 유물. 보스 → 달조각 + 전설 각인 선택.
- **런 내 화폐**: 생선 코인 🐟 (상점, 이벤트). 런 종료 시 소멸.
- **메타 화폐**: 털실 🧶 (사망해도 100% 보존), 달조각 🌙 (보스 처치 보상, 직업·고급 해금).

## 4. 조작 & 이동

### 4.1 키 배치 — ✅ 키 설정 화면 구현 (`src/input/bindings.ts`, `src/scenes/MenuScene.ts`)

배치 원칙: **왼손 = WASD 이동 + Q E R 스킬 + F 궁극기 + Space 점프 + Shift 대시, 오른손 = 마우스 (좌클릭 공격 · 우클릭 대시)**

- 이전 배치(방향키 + Ctrl 공격 + Z X C V)는 공격·대시·스킬이 왼손 새끼손가락에 몰리고, Ctrl+Shift 가 한/영 전환과 겹쳐서 변경
- 동작마다 키 2칸, Esc → 키 설정에서 키보드 키·마우스 버튼 아무거나 지정. 겹치면 서로 맞바꿈. 즉시 저장 (웹 localStorage / exe 세이브 폴더 keys.json)
- 키는 `KeyboardEvent.code`(물리 위치) 기준 → 한글 입력 모드에서도 WASD 동작
- 지정 불가: Esc(메뉴), F5·F11·F12, 윈도우 키, 한/영·한자 키, 1·2(직업 전환)

| 행동 | 키보드 | 게임패드 |
|---|---|---|
| 이동 | **A D** / ←→ (관성: 출발 가속 · 손 떼면 미끄러짐 · 반대로 꺾으면 브레이크) | 왼스틱 |

## 5. 전투 시스템

### 5.1 기본 스탯

| 스탯 | 기본값 | 설명 |
|---|---|---|
| 체력 | 100 (직업별 80~150) | |
| 공격력(ATK) | 10~13 | 모든 스킬 계수의 기준 |
| 공격 속도 | 1.0 | 애니메이션 재생 속도 배율 |
| 치명타 확률 / 피해 | 5% / 150% | |
| 이동 속도 | 150 px/s | |
| 쿨타임 감소 | 0% (최대 50%) | |
| 냥력 게이지 | 0~100 | 적중·피격으로 충전, 100에서 궁극기 |

> **수치 스케일**: 게임 안에서는 이 문서의 체력·공격력에 **×10**을 적용한다 (ATK 12 → 120, 궁극기 한 방 1,000+). 큰 숫자가 손맛을 키운다. 계수(%)는 그대로.

### 5.2 피해 공식

```
최종 피해 = ATK × 스킬 계수 × (1 + Σ피해 증가%) × 치명타 배율 × 원소 상성 × (1 − 대상 피해 감소%)
```

- **강인도(포이즈)**: 적마다 강인도 값이 있다. 누적 경직치가 넘으면 경직(스태거) → 콤보 연계 가능.
- **보스 그로기 게이지**: 가득 차면 4초 그로기 (받는 피해 +50%) — 공격적인 플레이 보상.
- **무적 프레임**: 대시 0.12초, 피격 후 0.6초 (깜빡임).

피해 계산(치명타 15%, ×1.6) → 대상 흰색 섬광 + 타격 방향으로 흔들림·찌그러짐 + 지푸라기 파편 → 데미지 숫자 팝(원소별 색, 치명타는 노랑 2배) → 히트 스파크 + 방사형 충격선(`fx_impact`) + 타격 방향 불꽃 → 히트스톱(물리·애니·트윈 정지, 치명타 ×1.35) → 화면 흔들림 → 궁극기 게이지 충전. 처치 시 먼지 폭발 + 파편 + 1.6초 뒤 부활.

## 6. 직업 6종 & 스킬

### 공통 규칙

- 모든 직업은 **두 발로 서서** 싸운다. 근접·원거리 직업은 무기(카타나, 활, 단검, 해머)를, 마법 직업은 지팡이·털실로 마법을 쓴다.
- 직업 = 영웅묘의 **방울**. 장착하면 나비의 털 무늬·의상·무기가 그 영웅묘 스타일로 바뀐다 (팔레트 스왑 + 의상/무기/모자 레이어). 모든 직업이 같은 포즈 데이터를 공유하고 무기 각도만 무기 종류별로 다르다.
- 직업마다 **기본공격 콤보 / 스킬 4종 중 2개 장착 / 궁극기 1종 / 패시브 / 고유 자원**.
- 해금: 검객·수호자 기본 해금 → 나머지는 달조각 + 스토리 진행으로 해금.
- 계수는 ATK 배율. 쿨타임은 초.

| 직업 | 영웅묘 (털) | 무기 | 역할 | 난이도 | 체험판 |
|---|---|---|---|---|---|
| 검객 | 치즈 (치즈 태비) | 묘도(고양이 카타나) | 근접 균형·반격 | ★ | ✅ |
| 마법사 | 먹물 (검은 고양이) | 별 지팡이 + 마녀 모자 | 원거리 원소 반응 | ★★ | ✅ |
| 사냥꾼 | 고등어 (고등어 태비) | 단궁 | 원거리 물리·함정 | ★★ | |
| 그림자 | 라떼 (샴) | 쌍단검 + 수리검 | 고기동 암살 | ★★★ | |
| 수호자 | 두부 (회색 통통이) | 참치 해머 + 냄비뚜껑 방패 | 탱커·반사 | ★ | |

### 8.3 도트 생성 파이프라인 (코드 기반)

이미지 생성 AI 대신 **코드로 도트를 그린다**. 주인공은 직립 고양이의 부위(머리·귀·몸통/옷·팔 2·다리 2·꼬리)와 레이어(무기·목도리/망토·모자)를 파라미터로 정의한 '리그'이고, 포즈 값(숙임, 발·손 위치, 무기 각도, 꼬리·망토 흔들림)만 바꾸면 모든 프레임이 일관된 품질로 양산된다. 무기는 앞손 위치(핸드 앵커)에 붙어서 직업마다 다른 무기로 바꿔 끼운다.

```
① 리그 정의 (부위 도형 + 관절)
② 포즈 키프레임 (애니메이션별 파라미터 곡선)
③ 래스터화 (픽셀 중심 샘플링 → 안티앨리어싱 없음)
④ 자동 음영 (좌상단 광원, 색 램프)
⑤ 디테일 레이어 (무늬·눈·코·의상·무기)
⑥ 셀아웃 외곽선
⑦ 수작업 보정 패치 (프레임별 픽셀 덮어쓰기 JSON)       ← M2
⑧ 팔레트 스왑 (직업별 털)                              ← M2
⑨ 아틀라스 굽기 (PNG + JSON) + 히트박스/루트모션 메타    ← M2
```

- **M0에서 ①~⑥ + ⑧ 프로토타입 구현됨**: `src/art/PixelCanvas.ts`, `src/art/sprites/cat.ts` — 검객(치즈·카타나·목도리)과 마법사(먹물·지팡이·망토·마녀 모자) 각 36프레임 (idle 16 / run 8 / attack 6 / jump 2 / fall 2 / dash 2)
- 검수: 게임 URL에 `#viewer`를 붙이면 애니메이션 뷰어, `#viewer-zoom`이면 대표 프레임 확대 뷰가 뜬다.
- 알려진 과제 (M2): 검은 고양이(마법사)는 어두운 배경에서 잘 안 보임 → 림라이트/밝은 외곽선 / 눈을 더 크게 (치비 매력) / 공격에 스미어 프레임 추가
- **교체 경로**: 손으로 그린 Aseprite 시트를 같은 키/프레임 이름으로 넣으면 코드 수정 없이 교체 (Aseprite JSON 아틀라스 포맷 호환).
- **품질 한계와 대응**: 코드 생성 도트는 일관성·양산성은 높지만, 얼굴 표정·무기 디테일·스미어(잔상) 프레임 같은 섬세한 부분은 손도트보다 약하다. → 대표 프레임(직업 6종 핵심 포즈, 보스)은 ⑦ 보정 패치로 마감한다.

## 10. 몬스터 & 보스

### 공통 설계 규칙

- **모든 공격은 예고한다**: 0.3~0.8초 텔레그래프 (눈 반짝 + 몸 움찔 + 빨간 경고 영역). 빠른 적일수록 예고 동작을 과장.
- **표준 애니 세트**: idle(4~6f) / move(6~8f) / telegraph(2~4f) / attack(4~8f) / hit(2f) / death(6~10f) + 고유 동작
- 체력은 1장 기준값. 챕터 배율: 1장 ×1.0 / 2장 ×1.6 / 3장 ×2.4 / 4장 ×3.4 / 5장 ×4.6
- **엘리트 접두사** (엘리트·미니보스에 1~2개): 불타는(화염 장판) / 얼어붙은(냉기 오라) / 분열하는(사망 시 2분열) / 흡혈하는 / 광폭한(체력 30% 이하 공속 2배) / 투명한 / 방패의(주기적 보호막) / 폭발하는(사망 시 폭발)

## 11. 맵 생성 & 방 구성

- **방 템플릿**: Tiled 에디터(.tmj)로 손으로 만든 방 청크. 크기 1화면(40×22.5타일) ~ 4화면. 출입구 태그(L/R/U/D) 포함.
- **챕터 그래프**: 시드 기반 RNG로 방 8~12개를 분기 그래프로 연결 → 마지막은 보스방. 같은 시드 = 같은 맵 (데일리 런, 버그 재현).
- **챕터당 템플릿 목표**: 전투방 20+, 특수방 각 3+ (반복감 최소화)

| 방 종류 | 비중 | 내용 |
|---|---|---|
| 전투 | 55% | 적 2~3웨이브 → 보상 (각인/코인/털실) |
| 엘리트 | 10% | 엘리트 1 + 졸개 → 유물 |
| 보물 | 7% | 유물 or 상자 미믹(!) |
| 상점 '냥이상회' | 8% | 유물·소모품·각인 재굴림 (코인) |
| 이벤트 | 10% | 텍스트 선택지 (예: '수상한 박스: 들어가 볼까?') |
| 휴식 | 7% | 박스 속 낮잠 → 체력 30% 회복 or 각인 강화 |
| 도전 | 3% | 제한시간 / 무피격 조건 → 고급 보상 |
| 비밀방 | 숨김 | 부서지는 벽, 고양이만 들어가는 좁은 틈 |

## 13. UI/UX & 접근성

- **HUD**: 좌상단 체력바 + 보호막 + 처치 수 / 좌하단 스킬 2 + 궁극기 게이지 / 우상단 코인·털실 / 우하단 참치캔
- **스킬바 (구현됨, `src/ui/SkillBar.ts`)**: [J 공격][U 스킬1][I 스킬2][O 궁극기][K 대시] — 아이콘 + 단축키 + 쿨타임 커튼과 남은 초 + 궁극기 게이지(가득 차면 금빛 점멸). 사용하면 테두리가 하얗게 번쩍, 쿨타임 중에 누르면 좌우로 흔들림, 쿨타임이 끝나면 반짝임
- HUD는 별도 씬(`HudScene`)이라 스킬 연출 중 카메라 줌·흔들림에 영향받지 않는다
- **폰트**: Galmuri (한글 도트 폰트, SIL OFL 1.1) — 라이선스 파일 동봉
- **메뉴**: 타이틀 / 설정 (그래픽·사운드·키·접근성) / 도감 / 크레딧
- **접근성**: 화면 흔들림·플래시 강도 0~100%, 색약 모드(원소 아이콘 모양 구분), 키 리바인딩, 게임 속도 70~100%, 자동 회복 보조 모드
- **언어**: 한국어 기본, 영어(정식판). 모든 텍스트는 i18n 키로 관리

### 15.2 핵심 설계

- **데이터 주도**: 직업/스킬/몬스터/유물/각인은 전부 `src/data/`의 타입 있는 데이터. 밸런스 조정 = 데이터 수정.
- **상태 머신(FSM)**: 플레이어·적 모두 상태 단위(Idle/Run/Attack/Hit…)로 로직 분리.
- **프레임 데이터 히트박스**: 애니메이션 프레임마다 히트박스·허트박스·캔슬 가능 구간을 정의.

```ts
// 예시: 검객 3타 (src/data/frames/blade.ts)
attack_3: {
  frames: 7, fps: 18,
  hitboxes: { 3: [{ x: 18, y: -20, w: 34, h: 16, coef: 1.6, knockback: 160, hitstop: 80 }] },
  cancelFrom: 5,           // 5프레임부터 대시/스킬로 캔슬 가능
  rootMotion: [0, 0, 2, 6, 3, 1, 0],  // 프레임별 전진량(px)
}
```

- **오브젝트 풀링**: 이펙트·투사체·데미지 숫자는 풀에서 재사용 (GC 끊김 방지).
- **히트스톱**: 물리 월드 일시정지 + 관련 스프라이트 애니 timeScale 0 → N ms 후 복귀.
- **세이브**: 버전 필드 + 마이그레이션 함수 체인. Electron은 원자적 쓰기(임시 파일 → rename) 구현됨.
- **성능 목표**: 60fps 고정, 동시 파티클 600개, 화면 내 적 30마리 (저사양 노트북 내장 그래픽 기준).
